# Design guide

Simple visual explanations of the formal workflow.

- [Current workflow](current-workflow.md): how the UP-012 example works today.
- [Proposed workflow](proposed-workflow.md): a reusable adapter for compatible validators.

**Manual** means code we write and maintain. **Generated** means files created
for a run. **Automatic execution** means the tool runs code we maintain.
Diagram boxes use shortened paths; source links give their full locations.

Keep each explanation to one concept and one Mermaid diagram. Add short text
where it helps. Mark proposed behavior explicitly and link the relevant source.
This README is the index.
